## Что делает бот

Бот распределяет кошельки между `LONG` и `SHORT`, выравнивает общий объём двух
сторон, открывает позиции, удерживает их заданное время и закрывает. Можно
торговать одним рынком или случайно выбирать рынок из списка на каждый цикл.

Поддерживаются два способа исполнения:

- `all-market` — все кошельки открываются и закрываются параллельными
  `MARKET + IOC` ордерами;
- `leader-follower` — лидер ставит `POST_ONLY` ордер, а фолловеры хеджируют его
  фактические исполнения.

Дополнительно бот умеет проверять балансы, закрывать все позиции, регистрировать
новые Lighter-аккаунты, пополнять их USDG, выводить средства обратно на кошельки
и отправлять отчёты в Telegram.

## Режимы

```text
Выбери режим:
  1 = Дельта-нейтральная торговля
  2 = Закрыть все позиции
  3 = Проверить балансы
  4 = Регистрация + пополнение USDG
  5 = Вывод средств
  0 = Выход
```

Режимы `2`, `3`, `4` и `5` выполняют задачу и завершают программу. Режим `2` также
подаёт сигнал остановки запущенному процессу режима `1`.
Режим `4` можно запускать повторно: существующие аккаунты сначала проходят
проверку регистрации, а затем пополняются.
Режим `5` параллельно выводит USDG на исходные кошельки. Перед ним закрой все
позиции через режим `2`. После задержки Lighter повторно запусти режим `5`:
готовые USDG будут автоматически получены в Robinhood Chain.

## Установка

Нужны Windows 10/11, Python 3.11+, Node.js и `npm`.

```powershell
git clone https://github.com/rud3wave/lighter-robinhood.git
cd lighter-robinhood
npm install
```

`npm install` создаст `.venv`, установит Python-зависимости и подготовит
локальные файлы. Повторная установка не перезаписывает существующие настройки и
входные данные.

## Настройка

### `global.js`

Укажи данные Telegram и обязательно замени пароль шифрования до первого запуска:

```js
export const TELEGRAM = {
  token: '',
  chatId: 0,
};

export const ENCRYPTION_PASSWORD = 'длинный-уникальный-пароль';
```

Telegram можно отключить, оставив пустой `token` и `chatId: 0`. Пароль защищает
приватные ключи в `databases/wallets.json`; после создания базы менять его нельзя.

### `input_data/privatekeys.txt`

Добавь EVM-приватные ключи, по одному на строку. Ключ должен содержать 64
шестнадцатеричных символа; префикс `0x` необязателен.

```text
0xPRIVATE_KEY_1
0xPRIVATE_KEY_2
```

### `input_data/proxies.txt`

Прокси необязательны. Поддерживаются форматы:

```text
ip:port
http://ip:port
http://user:password@ip:port
```

Бот проверяет весь пул, пропускает нерабочие прокси и распределяет рабочие по
кругу. Один прокси может использоваться несколькими кошельками. Если рабочих
прокси нет, соединение идёт через текущий IP.

Оба входных файла остаются обычным текстом. В базе шифруются только EVM- и
Lighter API-приватники; прокси не шифруются. В логах полные ключи, адреса и
данные авторизации прокси не показываются.

### `settings.py`

Все торговые настройки находятся в `settings.py`. Над каждой настройкой есть
комментарий простым языком, допустимые варианты и примеры. Перед запуском
особенно проверь рынки, плечо, процент баланса, группы кошельков, время удержания
и способ исполнения ордеров.

Сумма каждой записи в `GROUP_CONFIGS` должна совпадать с количеством готовых
торговых кошельков. Для каждого рынка из `TOKENS_TO_TRADE` должен быть свой
диапазон в `TOKEN_LEVERAGE`.

`ID_FILTER` позволяет запускать любой режим только для выбранных строк из
`privatekeys.txt`: поддерживаются отдельные ID, диапазоны, `<ID`, `>ID` и их
комбинации. Пустой список включает все кошельки; ID в логах не показываются.

## Запуск

Запускай команду из папки, где находится `package.json`:

```powershell
npm start
```

Для первого запуска удобен такой порядок:

1. Режим `4` — зарегистрировать новые аккаунты и пополнить USDG.
2. Режим `3` — проверить кошельки, прокси и поступление средств.
3. Режим `1` — запустить торговлю.

## Telegram и отчёты

Бот сообщает об открытии и закрытии позиций, PnL, комиссиях, funding, торговом
объёме, стоимости на `$100k`, балансах, депозитах и ошибках. Числа в консоли и
Telegram показываются максимум с двумя знаками после запятой.

## Проверка тестов

```powershell
npm test
```

Тесты не отправляют реальные транзакции и не открывают позиции.

## Важно

Бот отправляет реальные торговые ордера и блокчейн-транзакции. Дельта-нейтральная
позиция уменьшает направленный риск, но не исключает funding, спред,
проскальзывание, ошибки исполнения и ликвидацию.

Проект не гарантирует прибыль, начисление поинтов или множитель наград. Проверяй
настройки на малых суммах и не публикуй `global.js`, приватные ключи, прокси или
содержимое каталога `databases`.
