## Что делает бот

Часть кошельков ставит на рост цены. Другая часть ставит на падение. Бот
подбирает суммы так, чтобы обе стороны были примерно равны. Это снижает влияние
резких движений цены на общий баланс.

Бот сам открывает позиции, ждёт указанное время и закрывает их. Можно торговать
одной парой. Если добавить несколько пар, бот будет выбирать одну из них перед
каждым новым циклом.

В `settings.py` можно выбрать способ торговли:

- `all-market`: все кошельки действуют одновременно по текущей цене;
- `leader-follower`: сначала действует один кошелёк, затем остальные открывают
  противоположную сторону на нужную сумму.

Выбирай `all-market`, если важнее скорость. Выбирай `leader-follower`, если
важнее точнее выровнять суммы двух сторон и можно немного подождать.

Также бот проверяет балансы, регистрирует аккаунты, пополняет и выводит USDG,
закрывает открытые позиции и отправляет отчёты в Telegram.

## Режимы

```text
Выбери режим:
  1 = Дельта-нейтральная торговля
  2 = Закрыть все позиции
  3 = Проверить балансы
  4 = Регистрация + пополнение USDG
  5 = Вывод средств
  0 = Выход
```

`1`: запускает торговлю. Бот открывает позиции на рост и падение, ждёт указанное
в настройках время, затем закрывает их.

`2`: закрывает все открытые позиции и завершает работу. Если отдельно запущен
режим `1`, он тоже получит команду на остановку.

`3`: показывает баланс и открытые позиции каждого кошелька.

`4`: создаёт аккаунты Lighter и переводит на них весь доступный USDG. Режим можно
запускать повторно. Уже созданные аккаунты не будут созданы заново.

`5`: возвращает USDG с Lighter на кошельки. Перед выводом закрой все позиции
через режим `2`. Затем выбери способ:

- `Fast`: деньги приходят примерно за 15-20 секунд. Возможна комиссия;
- `Secure`: деньги приходят примерно через час. Этот способ состоит из двух
  шагов.

Для `Secure` порядок такой:

1. Выбери `5`, затем `Secure`. Бот создаст заявку.
2. Подожди столько, сколько напишет бот.
3. Снова выбери `5`, затем `Secure`. Бот получит готовые деньги на кошелёк.

После выполнения режимов `2`, `3`, `4` и `5` программа закрывается сама.

## Установка

Нужны Windows 10/11, Python 3.11+, Node.js и `npm`.

```powershell
git clone https://github.com/rud3wave/lighter-robinhood.git
cd lighter-robinhood
npm install
```

`npm install` установит всё необходимое и подготовит рабочие файлы. Повторный
запуск команды не удалит твои настройки и данные.

## Настройка

### `global.js`

Укажи данные Telegram и обязательно замени пароль шифрования до первого запуска:

```js
export const TELEGRAM = {
  token: '',
  chatId: 0,
};

export const ENCRYPTION_PASSWORD = 'длинный-уникальный-пароль';
```

Telegram можно отключить, оставив пустой `token` и `chatId: 0`. Пароль защищает
приватные ключи в `databases/wallets.json`; после создания базы менять его нельзя.

### `input_data/privatekeys.txt`

Добавь приватные ключи кошельков Robinhood Chain, по одному на строку. Каждый
ключ должен содержать 64 символа: цифры от `0` до `9` и буквы от `a` до `f`.
Префикс `0x` можно оставить или убрать.

### `input_data/proxies.txt`

Прокси необязательны. Поддерживаются форматы:

```text
ip:port
http://ip:port
http://user:password@ip:port
```

Бот проверяет все прокси и пропускает неработающие. Один рабочий прокси может
использоваться несколькими кошельками. Если ни один прокси не работает, бот
подключится через текущий IP.

Файлы `privatekeys.txt` и `proxies.txt` остаются обычным текстом. В локальной
базе приватные ключи хранятся в зашифрованном виде. Прокси не шифруются. В логах
полные ключи, адреса и пароли от прокси не показываются.

### `settings.py`

Все торговые настройки находятся в `settings.py`. Над каждой настройкой есть
простое описание и примеры. Перед запуском проверь торговые пары, размер позиции,
плечо, количество кошельков и время удержания.

`ID_FILTER` позволяет выбрать нужные кошельки по номеру строки в
`privatekeys.txt`. Оставь `[]`, чтобы использовать все кошельки. Примеры указаны
рядом с этой настройкой.

## Запуск

Запускай команду из папки, где находится `package.json`:

```powershell
npm start
```

Для первого запуска удобен такой порядок:

1. Режим `4`: зарегистрировать аккаунты и пополнить USDG.
2. Режим `3`: проверить кошельки, прокси и поступление денег.
3. Режим `1`: запустить торговлю.

## Telegram и отчёты

Бот сообщает об открытии и закрытии позиций, прибыли и убытке, комиссиях,
балансах, пополнениях, выводах и ошибках. Числа показываются максимум с двумя
знаками после запятой.

## Проверка тестов

```powershell
npm test
```

Тесты не отправляют реальные транзакции и не открывают позиции.

## Важно

Бот работает с реальными деньгами. Противоположные позиции уменьшают влияние
движения цены, но не гарантируют сохранность баланса. Возможны потери из-за
комиссий, разницы цен, периодических списаний и ошибок биржи.

Проект не гарантирует прибыль, начисление поинтов или множитель наград. Проверяй
настройки на малых суммах и не публикуй `global.js`, приватные ключи, прокси или
содержимое каталога `databases`.
